01MÓDULO 01Introdução ao desenvolvimento web

Conheça o caminho entre uma ideia e um site. Prepare seu ambiente e entenda o papel de cada tecnologia.

  • Como a internet e os navegadores funcionam
  • Editor de código e organização de arquivos
  • Seu primeiro contato com HTML, CSS e JavaScript
02MÓDULO 02HTML e estrutura de páginas

Organize conteúdo com HTML semântico.

  • Títulos, textos, links e imagens
  • Formulários e acessibilidade básica
  • Estrutura de uma landing page
03MÓDULO 03CSS e design responsivo

Traduza ideias visuais em layouts flexíveis.

  • Seletores, cores, tipografia e box model
  • Flexbox, Grid e media queries
  • Layouts que funcionam no celular
04MÓDULO 04JavaScript e interatividade

Adicione comportamento às suas interfaces.

  • Variáveis, funções e condições
  • DOM, eventos e estados da interface
  • Menus, acordeões e modais
05MÓDULO 05Git e GitHub

Acompanhe mudanças e apresente seu código.

  • Repositórios e commits
  • Branches e organização do trabalho
  • README e apresentação de projetos
06MÓDULO 06Projeto final e publicação

Reúna o aprendizado em um projeto completo.

  • Planejamento de um portfólio pessoal
  • Revisão de responsividade e acessibilidade
  • Publicação com GitHub Pages

ANTES DO PRIMEIRO PASSO

Alguma dúvida?
Vamos por partes.

As respostas abaixo descrevem a proposta fictícia deste curso.

Preciso saber programação?

Não. A proposta começa pelos fundamentos e avança gradualmente, com exercícios para praticar cada conceito.

O curso é online?

A proposta é de um curso totalmente online, com aulas para acompanhar no seu ritmo. Esta página não oferece aulas ou uma plataforma de ensino real.

Por quanto tempo tenho acesso?

No cenário demonstrativo, o acesso seria de 12 meses. Não há aquisição de acesso ou conteúdo disponível neste projeto de portfólio.

Preciso instalar algum programa?

Para praticar, você usaria um editor de código, como o Visual Studio Code, um navegador e o Git. O módulo inicial apresenta a preparação desse ambiente.

Consigo acompanhar pelo celular?

A proposta permite assistir às aulas pelo celular. Para escrever código, usar Git e desenvolver os projetos, recomenda-se um computador.

Como funciona a inscrição?

Os botões de inscrição abrem um aviso de demonstração. Não existe matrícula, coleta de dados, pagamento ou checkout real.
